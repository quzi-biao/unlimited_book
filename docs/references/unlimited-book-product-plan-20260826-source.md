无限之书 产品企划书

老许 / 2026-08-26 / 

一、背景与定位

我们相信，不管世界怎么改变，学习是人类永远不会改变的需求；但当世界已经彻底改变，学习的方法也一定会彻底改变。

人人都有好奇心，这是人最本原的驱力，但这个时代正在滥用它——用无尽的信息流和即时反馈，怂恿人把好奇心挥霍在只能消耗、无法积累的地方。娱乐至死，不是危言。我们要做的，是从这片环境里把一个人的注意力和时间夺回来，交还给他自己。

我们要接住的，是前人接不住的东西。这一代孩子从认得第一个字起，就有可能拥有一座始终在场、连续生长的思想容器——人类第一代拥有连续外化思想容器的人，有可能从这一代开始。

无限之书是一个以人工智能驱动的个人知识库。单一版本，全龄贯穿，从一个人认识第一个字起陪伴其长长的一生，不另设儿童版与成人版。它叫无限之书：书是人类给"被积累下来的知识"最古老的比喻；"无限"指没有最后一页，一个人用得越久，它越厚。它当然也是更大的书库、也是学习软件，只是远远超越这两者。

它的形态是软件，也是硬件。内核是跟随账号存在的个人应用；外壳是会单独售卖的专用终端——一台为"读书和长大"从头设计的设备。骨是软件，壳是硬件，会生长的始终是软件；手机、平板、桌面、网页端也都能进同一座库。

双模。平时是"无限之书"：不设终点的生长。使用者（及监护人，对未成年人）实在有需要时，可切到"有限之书"：采纳一个外部范围（例如"初中二年级物理知识点"），照见自己还欠缺什么、还需要补什么。范围由使用者与监护人决定采纳，系统不替用户定义。

书不是库存，是活水。出版（如果还用这个词）是内容生产的起点，不是终点——一本书在被阅读的过程中持续生长。对孩子，任何一个问题都能得到一页专属的回应，而不是在已有的书里找不到就再也没有了；对家长，买回家的不是一个会被翻完、会过时的内容库，而是一个会跟着孩子的问题不断长下去的书。水是活的，河道是修过的——活水的自由，由后面的生成引擎与安全意识共同兜住。

我们做的不是一款内容产品，是一个人长长的一生里知识成长的思想容器。在当前阶段，我们暂且把它称为一个终身学习工具——这个称呼是工作定义，待全局讨论进一步成形后再校准。

二、设计的第一性原理

（一）提示性基底。系统持续把"万物互联"的提示摆在用户面前，放大使用者自己头脑里的风暴。系统只是提示者，能够判断价值的是人；使用者错过了就错过，重要的是工具一直在提醒"万物互联"，让使用者建立起以连接思考的习惯和理念。真正的创新，是工具加上使用者头脑中的风暴组合而成的，工具说到底只是工具。

（二）被建模的学习轨迹是地基。一个人的知识不是条目的堆积，是"一个点怎么连到下一个点"的轨迹。这座被建模的轨迹是全部功能的单一来源，换不走、抄不去，是产品真正不可迁移的资产。

（三）主权在用户。数据归用户。系统提示不裁决；吸收可以被动，判断必须主动，探索必须主动；不替用户做主。边用边认识一个人早就是现实——很多平台一直在做，只是做给你自己之外的别人，拿去变现。我们的不同，是把这份认识的主权夺回到使用者自己手里。

（四）反娱乐至死。连接的呈现以"新奇"而非"数量"为筛选标准；新奇必须织入用户自己的图、改变其想问题的方式，而不是成为下一轮刺激。打破信息茧房是强制的设计要求，不是可选项。

三、系统架构分层

全系统建立在被建模的学习轨迹之上，并坐落在分形阅读范式这一交互基底上。由四层功能叠成。

（一）第一层 积累与轨迹。每一次打开、停留、反复回看，记录为轨迹。可视化为一座知识树：亮部是走过的，暗部是尚未触及的可能性。每个被点亮的点向外展现有限的相关性——科学是来龙去脉、层层堆叠引发新发现；人文则展现本学科的相邻内容，与各科方向的最近一步进展，多条并存且标临时，不显成唯一条。暗部不靠系统强推，而靠使用者自己看见后被好奇拽过去；可能性空间以"相邻可能性"生成，从每个被点亮的点向外露出相邻的可能，不预设全图、不替用户做主。这是"拉"式的反茧房。

（二）第二层 被动无感掌握。基于记忆规律（间隔重复，按所需频率在差不多的时间与环境里推到眼前、用几次便焊死）与"跳起来够得着"（最近发展区，给每个人恰好伸一下就能够到的挑战），系统在无感环境里把该复习、该挑战的内容推到眼前。系统在此判认知状态（忘了没有、难度合不合适），不判思想价值。

（三）第三层 主动连接（提示性基底）。储备的知识点越多，相互发生关联的几率越高，发现未曾被发现的连接的可能性也越高。系统在跨域优先、意外度、当下相关三项标准下生成候选连接提示；跨域优先落实打破茧房。提示的呈现说"你有没有想过 A 和 B 可能连"，绝不说" A 和 B 是连的，因为……"。

（四）第四层 被改变的人。产品不交付连接，交付"能以连接方式思考的人"。包含鼓励独立思考的纠错教程：不替用户把关，而是用机制培养用户自己把关——让用户参与审查与修正，这层既是安全冗余，也是学习功能。

四、功能模块与开发任务

以下每个模块都是一项开发任务。模块内"待解决"为该模块当前未闭合的设计或技术口子，需在开发中补全或提交讨论。

轨迹建模引擎。

建立用户知识轨迹的数据模型：节点（知识点）、边（连接）、掌握状态（擦过／练过／连过／真正长在自己身上）。这是全系统的地基，其他模块皆读写此模型。

知识树可视化。

把轨迹渲染为可感的知识树，一点点点亮；亮部与暗部对比，生出张力。暗部即可能性空间，按"有限相关性"标准向外露出候选连接，以"相邻可能性"生成，不预设全图、不替用户做主。展现相关性时，科学走因果推导；人文展现本学科的相邻内容与各科方向的最近一步进展，多条并存且标临时，不显成唯一条。

知识树一身三任：它是导航结构，回应"会不会迷路"；它是认知结构的外化，促进理解与保持；它还是成就的载体。完成感由行为定义，而非由内容的边界定义——一页读完，是一次小的完成；一次坐下来的探索形成一本书收进书架，是中等尺度的完成，且有实体的陈列证据；当某个领域的枝叶足够茂密，树呈现出可辨认的形态（"我的昆虫世界长成了一棵大树"），是长尺度的完成，且是孩子自己长出来的，不是系统规定的进度。三种完成共同的铁律是：机制隐身于书。孩子的注意力永远停在探索本身，一棵新枝、一本朋友送来的书、一扇新领域的门，只在探索发生之后显形，绝不前置激励、绝不挂进度条——探索一旦变成任务，好奇心就会枯萎。

被动学习引擎。

实现间隔重复调度器与最近发展区难度校准。判定用户的认知状态以决定何时、以何种无感方式把内容推到眼前。此引擎判认知状态，不判思想价值。

连接提示引擎。

生成候选连接：选择标准＝图上距离（远域优先）、意外度（违反预期）、当下相关。跨域优先为强制。提示为提议、非强加；判断归人。

纠错与审查教程。

把内容纠错设计为鼓励独立思考的使用指导：显式邀请用户参与审查与修正，绝不无感处理。此模块必须可见、由用户参与，与"无感吸收"严格分属两半（吸收被动、判断主动）。

表现与吸引层。

从画面到内容都要足够吸引人，让使用者愿意继续。包含趣味知识增强记忆、鼓励使用者拿学到的内容去显摆（落在用户↔用户或用户↔自己，不落平台）、个性化只个性化"形式"不个性化"内容过滤"（内容池保住反茧房配额）、招数用老须结构化变化（服务于织入，不服务于下一刺激）。表现算法的目标函数必须锁在用户的长进，不锁在平台的参与度——此护栏作为架构级技术约束，由开发组在系统中落实，防止被偷改回参与度优化。

有限之书诊断模式。

使用者与监护人采纳一个外部范围后，在同一座轨迹上渲染"缺口视图"，显示还欠缺什么、还需补什么。须框定为"可选补"，不框定为"你不足"；必须是同容器的视图，不是第二本独立的书；外部点集（如课程图谱）按人教版教材供给，以后逐步增加。

邻域共学信号。

开关控制是否可见"周边有多少人在学同一内容"，周边可为一、三、五公里；不知对方是谁，只给一个聚合数字，人多则圆点大而亮，反之小而暗。默认关；儿童开启须经监护人把关；战略含义为陪伴（非社区选址）。数据底盘须设计为聚合、不留存、永不连身份（端上计算优先，或明确位置粗化、三元组不存储），具体方案交开发小组决定。

物理沉淀与导出。

把工具上的内容简单输出为纸质打印件、贴墙海报。导出须是策展过的切片（一枝、一连接、一页、一条趣味知识），由用户选或系统建议不代印；格式须开放（如 PDF 等标准打印格式），任何店可印；质量门槛高，海报模板须真好看；不可为"好印"重塑用户内容。

专用终端。

形态为平板，软件之外的硬件载体。须服务于"无感被动环境"与"主权在用户"两条。

儿童边界与监护人系统，含监护人观察端。

算法依据一般儿童知识与兴趣特征划界；越界需父母授权；整个儿童期建立在监护人许可之上。有限之书模式的开启，对未成年人由监护人决定。安全底线与内容安全层的具体设计交开发组，与此模块及纠错教程衔接。

第一波使用者由父母购买、给孩子使用，所以监护人观察端是说服家长的关键。它立三条绝对禁令：不人格测评（不给孩子贴"逻辑型""艺术型"之类的标签——儿童的特质正在形成，标签是另一种茧房）；不做覆盖率（完成度地图只存在于编辑后台，永不进入监护人视野）；不做补全提示（绝不建议"该补哪类内容了"）。禁令之内提供四类内容：知识树回顾，基调是独特性——"你的孩子长出了一棵别人家没有的树"，树是兴趣的写照，不是进度的报表；行为事实摘要，只陈述、不解读、不与任何"平均水平"比较；沟通建议，每条事实旁附一个可以开启对话的问题，递上开启理解的钥匙，而非替监护人理解孩子；系统对使用者偏好的理解，对监护人完全透明，可见、可重置、可逐项关闭。每周探险报将四类内容聚成周节奏的推送（本周的新枝、表达时刻集锦、一条沟通建议），载体用小程序或网页而非独立应用——监护人的查看是每周级频率。对成人使用者，观察转向自己（好奇心去了哪里、知识树月报、探索多样性），系统只呈现、不干预。

主权与数据架构。

数据归用户，可携带、可脱离（随时导出抱走）。聚合计算不留存、不连身份。模型可换，而这套体系（提示词装配、轨迹模型、反茧房逻辑、对使用者的理解、评测集、装配日志）是长留的资产；模型可换而体系为资产的技术实现路径交开发组。

分形阅读引擎。

无限之书的"无限"有三重：体验的无限（边界不可见、分支走不完，任何提问都不撞"此路不通"的墙）；内容的无限（路径依读者即时生成，按需生成、没有库存上限，不是库很大，而是没有上限）；结构的无限，即前两重的共同机制——分形阅读范式。

抽掉具体载体之后，范式本身是：每个知识节点＝（内容、主模态、锚点集、出口集），展开算子依据锚点生成结构同型的新节点——新节点同样拥有内容、锚点与出口集，可以继续展开。这种递归的自相似，正是分形：读者的每一次展开，都是对知识结构的一次放大。

分形的灵魂在于一个常被忽略的事实：分形的细节不是存储的，是计算的。曼德博集合每一次放大涌现的新细节，不在任何数据库里预先存着，而是在放大发生的那一刻被算出来的。这正是"为什么必须是人工智能"的数学隐喻——预先编写的内容无论多么庞大，嵌套深度必然有限，只能构成一棵"很深的树"，永远不是分形；人工智能的即时生成第一次让知识呈现获得分形的本质：看到哪里，就在哪里细化，深度无界。

这个范式有清晰的历史先例。Ted Nelson 在 1967 年提出 stretchtext（伸缩文本，文本可在原位展开出更详细的版本），却因为不可能为每一段预写无限层的展开而搁浅；Bret Victor 在 2011 年的 Explorable Explanations 展示了可探索文档的惊人潜力，但每一份都需要精工手作、无法泛化。生成能力补上了这两个先例共同缺失的拼图：展开由生成而非预制支撑，自相似深度才能无界。

设计定律：主模态的选择不是审美偏好，而是由解码能力与阅读目的决定的产品变量。低龄使用者文字信道失真最大，以图像为主模态；目的性成人文本信息密度更高，适配目的性阅读；感受性阅读偏向图像与视频的沉浸。每种模态是一条失真方向不同的有噪信道，多模态协同的本质，是对同一知识做三角测量——以互补方向的冗余降低总失真。

生成引擎（四层装配＋安全底线）。

每一页书由动态提示词装配生成，四层加一条底线：

L0 全局基座层（产品级慢变量）。规定页面的基础结构——一个真实对象、一句核心知识、讲解、多个出口——以及适龄语言总规范、知识准确性要求，与基础画风体系（书感、绘本质感）。决定"这是一本什么气质的书"，是品牌资产，由运营后台集中维护，变更等同于产品改版，必须走版本管理、评测集回归、灰度发布。

L1 懂读者层（用户级慢变量）。记录使用者的理解水平、长期兴趣、偏好的讲法与画风，随使用逐步沉淀。这是系统慢慢摸清你的那一层，而非给你的定性。终端上的风格与音色选择界面，是这一层显式信号的采集入口。

L2 路径上下文层（会话级中变量）。最易被忽略，却是"书感"的技术保障。从火山页框选火山口生成子页时，提示词必须携带探索链的血缘——父页讲过什么（承接、避免重复）、本次追问脉络、已有页面的视觉基因（保证同一本书的页面像同一本书：火山页里的那只鹦鹉，在子页里应该还是那只鹦鹉）。没有 L2，知识树上的每一页都像从不同的书里撕下来的。它同时也是非线性阅读里连贯补偿的生成侧。

L3 当前请求层（即时快变量）。本次触发源——输入的话题、框选区域的语义、期望的页面类型与即时约束。在分形语言里，L3 承载的正是锚点的语义。

S 安全约束层（底线）。适龄边界、敏感话题清单、事实性硬要求、禁止诱导、生成标识——任何层（尤其是 L1 与 L3）都不得覆盖或稀释。工程上实现三道关：生成前请求过滤→提示词内硬约束段永远置顶→生成后文本与图像双审。儿童倾向认为人工智能不会犯错，这使得 S 层不是合规成本，而是循证的设计义务。

层间冲突规则：S 否决一切；表现力参数就近优先（L3 覆盖 L2 覆盖 L1 覆盖 L0）；结构性参数只升不降（任何层不得移除 L0 规定的页面结构与准确性要求）；所有冲突留痕入装配日志，供运营判断 L0 规则是否需要修订。

模型选型与资产观。生成一页不是调用一个模型，而是一条多模型流水线：框选区域理解必须快（孩子的手指还按在屏幕上），独立选型快模型；话题理解与页面配图可异步入探索队列，可为质量选慢模型——这个"可以慢"的自由度，是专用终端加任务队列形态给模型选型的隐性馈赠。儿童场景六条准则：事实可靠优先于创造（高信任乘幻觉是本产品独有的风险组合）；安全双保险（优先选自带强对齐的模型，但平台侧 S 层三道关永远独立存在，不把安全外包给厂商）；中文儿童语言质量单独评测；国内部署选用已完成生成式人工智能备案的模型；单页成本即定价决策（直接决定点数与订阅权益上限）；图像看一致性优先于单图惊艳（风格漂移会破坏 L2 的视觉连续性）。评测集驱动换型：建立黄金话题集，从事实准确性、适龄性、安全性、风格一致性四轴打分，任何模型或提示词变更必须跑回归——没有评测集，换模型就是赌博；有评测集，模型市场的每次洗牌都是免费升级。成本质量分级路由：书的首页与家长可见内容用强模型，扩展性任务用性价比模型。模型市场每季度洗牌，但四层提示词体系、对使用者的理解、评测集、装配日志是随时间增值的自有资产——护城河在体系，不在某个模型。

建设次序遵循"先底线、后书感、再个性化"：S 层三道关与 L0 基座最先；L2 路径上下文其次，它决定探索链是否有书感；评测集与装配日志同步建立；L1 个性化最后——个性化是体验的放大器，不是成立条件。

五、贯穿全局的底层原则

以下原则贯穿所有模块，是开发的硬约束。

主权在用户：数据归用户，系统提示不裁决，不替用户做主。 

（二）提示者不判断价值：系统摆候选，人仲裁；错过就错过。 

护城河在体系：模型可换，四层装配、轨迹模型、反茧房逻辑、评测集、装配日志是长留资产。 

反茧房是必须：跨域优先、反茧房配额为强制设计。 

吸收被动、判断主动、探索主动：无感只用于掌握节奏，绝不用于真相判断与纠错。 

目标函数锁在用户长进：表现与推荐算法不得优化平台参与度，护栏以架构级约束落实。 

个性化形式、不个性化内容过滤：递送的样子可个性化，内容池保住反茧房。 

单版本全龄：不另设儿童版与成人版，差异只在监护人许可与能力逐步移交。 

反茧房分级治理：按场景分为三级——目的性模式，路径服务于目标，无茧房概念；感受性模式，不设配额，茧房即产品，仅给自我观察数据、不干预；未成年人全模式，反茧房配额强制生效（偏好正在形成，茧房是剥夺）。未成年人具体机制：个性化大胆作用于样式维（怎么讲、怎么画），谨慎作用于内容维（讲什么）；推荐出口保留新颖性配额（约三分之一指向偏好之外的领域）；监控探索领域分布熵，若持续收窄，自动放大新颖性配额。 

主模态由解码能力与目的决定：低龄以图像为主模态，随解码成熟过渡到文本；多模态协同是对同一知识做三角测量，降低总失真。 

观察端只呈现事实、不评判：监护人端三禁令（不人格测评、不做覆盖率、不做补全提示）；看见不转化为监视。

六、战略位置与边界

（一）在整体版图中的位置：独立产品、独立项目。与原创土壤、青少年教育、博物村均无隶属关系，不作为其中任何一项的终端载体或延伸产品。

（二）第一波使用者：硬件由父母购买、给孩子使用。需要说服的，是对现行教育不满、且相信本产品逻辑与愿景的那部分家长。孩子是使用者，父母是购买决策人，二者都要被产品叙事接住——对孩子接住的是每一个问题，对父母给到的是"从黑箱到可见"的安心。

（三）商业模式：硬件售卖，加按月 token（人工智能调用额度）。主权在用户、数据归用户的原则不变；token 是算力消耗的对价，不附带对数据或注意力的额外索取。

写在最后

我们做的，是把一个古老的比喻接上新的可能：书，第一次能够陪着一个人从认字长到老，能够记下他是怎么想通的，能够在他需要时把万物连起来摆到他眼前。它不替任何人思考，也不替任何人决定——它只是让思考这件事，重新变得属于自己。书不再是仓库里的库存，而成了跟着人生长的活水；没有最后一页的焦虑，被"你走到了这里"的完成感取代。

面向未来的学习，也许就从这样的一个工具开始。
