# 个人知识树视角 A（2026-11-23，本地）

客户确认“一个用户一个知识树”。阅读页的整本书命名为「无限之书」；书架提供该个人知识树的入口；话题及其延伸构成这棵树的节点和分枝。

知识树图增加一个纯展示的“我的知识树”根部，已有的真实根话题分枝接入共同主干。这个展示根不会写入账号数据、伪造生成父路径、添加学习记录或被删除。独立搜索的两个话题仍保持各自的真实关系，不会自动互相挂接；节点翻页限于当前真实相连的话题分枝。

本地改动：

- 知识树呈现一个个人根部及其话题分枝，保留探索路径点亮、未探索节点变暗、拖动、触摸滚动、缩放和键盘导航。
- 阅读导航把跨话题的统一书名显示为「无限之书」，并保留当前真实分枝的翻页范围。
- 原书架突出「我的无限之书」入口；历史图册继续作为已有图册展示。
- 切换公共内容来源时，当前来源呈现新探索入口，已探索的公共节点继续作为同一棵个人树中的分枝；安全模式可重开本人已纳入的公开轨迹，但不能直接打开另一个未选来源的新节点。
- 公共内容来源选择仍为内容入口，探索模式选择沿用既有安全边界；不改存储中的节点父子关系，也不迁移或删除用户数据。

验证：个人树单元测试覆盖多话题无重叠、真实父子层级、统一书名、分枝内翻页和 1500 层深链。桌面与手机浏览器测试验证一根多枝、书名一致、根部可见、卡片布局、缩放、键盘、触摸、拖动、空树和点击节点后的个人书名。17 项服务端集成测试通过，含切换公共来源后保留已探索分枝和安全模式权限；19 组阅读回归、9 种删除场景、12 类节点操作浏览器检查通过。
