# 恢复原版生图流程（本地验证）

用户要求在既有产品上升级，不擅自增加画风。本次没有提交、推送或部署。

## 原因与修复

知识树此前把包含正文、锚点 JSON 和绘本要求的整段内容直接送入图片模型，绕过设备所选提示词。图片模型名称仍为 gpt-image-2，但实际图片指令发生了变化。

- 原书架与知识树共用设备画风读取逻辑，设备选择优先，默认「酷炫科普风」。空库回退使用原种子文件提取的完整模板。
- 四份模板（统一、主题、框选识别、深入探索）的 MD5 与旧本地数据库逐项一致，没有改写模板。图片供应商、模型、质量、画幅适配仍走原有函数。
- 文字生图只把话题送入原模板；明确的文字深入附带父页标题；框选沿用原识别和图生图函数。解释和复核单独执行，不把页面结构要求送进图片提示词。
- 删除新账号页重复添加的绘本／水彩等选项；原「设置 → 画风」继续生效。
- 底部搜索不再把当前页面当父节点；原图册仍按书名查找，已发布公共根仍直接打开。个人生成记录交给后端按版本和实际模板签名查缓存，不以同名旧节点短路。
- 缓存身份绑定实际模板内容与所用模型。旧记录、笔记和点亮数据保留；修复后生成使用新的缓存身份。

## 历史话题挂接修复

用户随后明确授权处理历史错误关系。本机 knowledge 库中，确认同一读者的「长江」「黄河」误挂在「量子力学的基本概念」下，已将两条个人节点的 parentId 清空，使三者同级。脚本按精确节点清单执行，写入前保存权限为 0600 的备份；事务内比对其余个人节点、图片内容和学习事件未变化。原始图片标识与当时的生成血缘保留，避免伪造原生成来源或破坏缓存及笔记引用。

后续生成从个人树读取祖先上下文；当个人路径与原生成来源不同，缓存身份加入修正后的路径，防止继续复用含错误祖先的结果。路径未变的现有缓存身份保留。回归覆盖备份、错误清单整批拒绝、幂等、笔记和点亮保留、子节点保留、上下文和缓存隔离；57 项后端测试通过。
