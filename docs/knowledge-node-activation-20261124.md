# 公共知识树节点停用

后台选中节点后，详情操作区提供“停用节点”或“启用节点”。确认框说明受影响的后代数量；树结构列表显示节点自身的停用状态。

- 停用只修改当前树节点的 `active` 标记，不删除节点、图文或学习记录。
- 草稿和已发布树均可操作。读者下次同步时，该节点、全局后代和沿该分支生成的个人后代隐藏；父图不再返回指向隐藏子节点的跳转框。
- 再次启用后，原有内容和探索记录恢复。祖先仍停用时，后代保持隐藏；单独停用过的后代也不会被自动启用。
- 同一图文在其他树的启用引用仍可访问，状态不作用于共享资源。
- 公共内容直开、语音和继续生成均检查祖先状态，不能从旧的个人引用绕过停用。历史学习记录仍可补传和导出。
- 发布只要求可见分支的图文与跳转框完整。已发布树重新启用节点时会再次校验，防止公开尚未审核的内容。停用最后一个根节点可以暂时隐藏整棵树；重新发布仍须有启用的根节点。

接口：`PATCH /api/admin/knowledge/trees/:treeId/nodes/:id/active`，参数为 `active` 和当前树的 `revision`。仅超级管理员可访问，过期版本返回 409。
