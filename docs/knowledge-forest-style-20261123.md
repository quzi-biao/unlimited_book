# 书架森林样式 D（2026-11-23，本地）

用户从四种知识树预览中选择 D「书架森林」。本次在原阅读器的知识树入口实现该方向：独立根话题各成一棵树，主题书页位于树干底部，下级书页向上分枝，共同连接「我的书架」。配色沿用深蓝背景与金色，已探索书页及路径点亮，未探索书页保持暗色。

## 交互与布局

- 点击主题或分枝书页继续使用原阅读器，也支持键盘 Enter / 空格。
- 电脑可拖动画布，手机保留原生滑动，提供放大、缩小、适合画布和复位。
- 知识树面板在桌面上加宽以展示并排森林，其他面板保持原尺寸。
- 节点根据真实 `parentKey` 排布，每个子树单独分配宽度，避免卡片重叠；长标题显示省略及完整悬浮标题。
- 只展示探索路径和下一层入口；祖先路径点亮不修改祖先的已探索记录。
- 断链或循环仅在显示布局中容错，不改存储关系；尚无下级节点的主题以幼树呈现，不添加虚构知识节点。

布局逻辑位于 `web/src/knowledge/forestLayout.js`，绘图位于 `ForestDrawing.jsx`，交互入口为 `TreeMap.jsx`，样式位于 `forest.css`。本次不修改服务端、生成模型、提示词或用户数据。
