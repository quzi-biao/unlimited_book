## 产品定位与边界

无限之书是 AI 驱动、随个人一生持续生长的个人知识库与思想容器。“终身学习工具”是原文的工作定义，仍可在后续讨论中校准。内容在阅读中按需生成，没有最后一页；积累的是用户如何从一个知识点走到另一个知识点的轨迹。

- 单版本、全龄贯穿，不另设儿童版与成人版；年龄差异通过能力适配、监护人许可与权限逐步移交体现。
- 软件是内核，个人知识库跟随账号存在；专用平板是单独售卖的硬件载体，手机、平板、桌面、网页端均可进入同一座库。这是目标形态，不代表现有账号与多端同步已完成。
- 第一波由父母购买、孩子使用，需要同时承接孩子的好奇心与家长对使用过程可见的需求。
- 属于独立产品、独立项目，与原创土壤、青少年教育、博物村均无隶属关系。
- 商业模式为硬件售卖加按月 token，即 AI 调用额度；算力付费不附带对用户数据或注意力的额外索取。此处没有确定价格、额度或套餐实现。

## 两种阅读模式

- **无限之书**：以兴趣驱动、不预设终点的持续探索。
- **有限之书**：用户及监护人主动采纳外部范围后，在同一份轨迹上显示缺口，是同一容器的视图，不建立第二套独立知识库。缺口表述为“可选补”，而非“你不足”；范围不由系统替用户决定。原文计划从人教版教材的外部知识点集开始，逐步增加。未成年人开启此模式由监护人决定。

## 核心设计原则

1. **主权在用户**：数据归用户，可携带、可导出、可脱离；系统提示而不裁决，不替用户判断思想价值。
2. **轨迹是地基**：知识节点、连接、掌握状态构成全部功能共同读写的数据基础，不能只积累孤立内容条目。
3. **吸收被动，判断与探索主动**：复习与难度安排可无感，纠错与审查必须显式邀请用户参与。
4. **连接是提议**：提示“你有没有想过 A 和 B 可能连”，不替用户宣告唯一连接或正确解释。
5. **目标是用户长进**：表现与推荐机制不能以平台参与度为优化目标；新奇要融入用户自己的知识结构，不靠不断刺激维持停留。
6. **形式可个性化**：讲法、画风、音色可适配，内容过滤须遵守下述场景与年龄分级约束。
7. **长期资产在体系**：模型可以替换，提示词装配、轨迹模型、对使用者的理解、反茧房逻辑、评测集和装配日志应持续积累。数据归用户与资产积累两项原则需同时保留。

## 四层能力与知识树

| 层次 | 企划要求 |
| --- | --- |
| 积累与轨迹 | 记录打开、停留、重复回看；建模知识节点、连接以及“擦过／练过／连过／真正长在自己身上”的掌握状态。 |
| 被动无感掌握 | 间隔重复与最近发展区难度校准，判断是否遗忘、挑战是否合适，不判断思想价值。 |
| 主动连接 | 按跨域优先、意外度、当下相关生成候选连接，仲裁权属于人。 |
| 被改变的人 | 培养以连接方式思考和独立纠错的能力，让用户参与审查与修正。 |

知识树同时承担导航、认知结构外化和成就呈现。亮部是已走过的轨迹，暗部从当前节点露出有限的相邻可能性；不预先绘制全图，不用系统强推代替好奇心。科学侧重因果与推导，人文显示多条并存、标为临时的相邻解释和跨学科进展。

完成感来自读完一页、一次探索收成一本书、一个领域逐渐长出枝叶。成就随探索发生之后显形，不前置奖励、不用学习进度条把探索变成任务。原文此处讨论学习激励，不据此自动改变现有生成任务的等待提示。

## 反茧房的分级规则

原文前文强调反茧房为硬约束，后文给出场景与年龄细分；引用时须同时保留这层限定。

- 成人目的性模式：路径服务于用户目标，原文不以茧房治理为目标。
- 成人感受性模式：不设反茧房配额，只提供自我观察数据，不主动干预。
- 未成年人所有模式：强制保留新颖性配额；约三分之一推荐出口指向已有偏好之外的领域。持续监控探索领域分布熵，若领域长期收窄，放大新颖性配额。
- 未成年人个性化大胆作用于样式，谨慎作用于内容；“约三分之一”是企划中的近似要求，不是本次新增的运行参数。

## 分形阅读范式

每个知识节点由内容、主模态、锚点集与出口集构成；根据锚点展开时，即时生成结构同型的新节点，仍可继续展开。企划中的“无限”包括体验、内容与递归结构三层含义。

主模态由解码能力与阅读目的决定：低龄主要用图像，理解能力成熟后可转向文本；目的性阅读重信息密度，感受性阅读可偏向图像和视频。多模态围绕同一知识互补，不能只为视觉效果叠加内容。

## 生成引擎与装配规则

| 层 | 作用 |
| --- | --- |
| L0 全局基座 | 产品级慢变量：真实对象、核心知识句、讲解、多个出口的页面结构，以及适龄语言、事实准确性、基础画风与书感。由运营后台集中维护；变更要版本管理、评测回归与灰度发布。 |
| L1 懂读者 | 用户级慢变量：理解水平、长期兴趣、偏好的讲法与画风；音色和风格选择是显式信号，不应转为人格定性。 |
| L2 路径上下文 | 会话级变量：父页已讲内容、追问链、视觉基因；承接已有内容、避免重复、保持角色与画风连续。 |
| L3 当前请求 | 即时变量：本次话题、框选区域语义、页面类型与即时约束，承载当前锚点语义。 |
| S 安全约束 | 适龄边界、敏感话题、事实性要求、禁止诱导和生成标识；任何其他层都不能覆盖或稀释。 |

- 安全三道关：生成前过滤请求；提示词硬约束段始终置顶；生成后文本与图像双审。
- 冲突优先级：S 否决一切；表现参数按 L3 → L2 → L1 → L0 就近优先；结构与准确性要求只升不降，不能删除 L0 要求。
- 所有层间冲突留在装配日志中，供运营判断是否修订 L0。
- 多模型分工：框选区域理解强调速度，话题理解和配图可以通过探索队列异步完成；首页与家长可见内容倾向强模型，扩展性任务可按成本质量分级。
- 原文选型要求：事实可靠、平台独立安全保障、中文儿童语言专项评测、国内部署采用已完成相关备案的模型、单页成本与权益匹配、视觉一致性。此处记录选型意图，不构成对当前服务合规或能力的核验。
- 黄金话题集至少覆盖事实准确性、适龄性、安全性、风格一致性；模型或提示词变更均应回归。
- **企划建设顺序**：先 S 三道关与 L0；再 L2；评测集与装配日志同步；L1 个性化最后。本次仅记录顺序，不自动启动开发。

## 监护人与儿童边界

儿童期以监护人许可为基础，越过适龄内容边界需要授权；能力与权限随成长逐步移交。

监护人观察端有三项禁令：不做人格测评、不展示覆盖率、不提示补全知识类型。可展示四类信息：

1. 知识树回顾，突出兴趣的独特性，不作为进度报表。
2. 行为事实摘要，只陈述、不解读、不与平均水平比较。
3. 与事实相邻的沟通建议，以问题帮助家长开启对话，不代替家长理解孩子。
4. 系统对偏好的理解，向监护人透明，可重置、可逐项关闭。

每周探险报聚合新枝、表达时刻和沟通建议，计划通过小程序或网页提供，不另做独立观察端应用。成人转为自我观察，例如好奇心去向、知识树月报和探索多样性，只呈现、不干预。

有限之书的用户主动缺口诊断与监护人观察端“不做覆盖率、不做补全提示”需在交互和权限上明确区分。企划未给出完整细则，不能据此向监护人推送补课建议。

## 其他功能规划

- **邻域共学信号**：默认关闭，未成年人开启须经监护人许可；可选择一、三、五公里，只显示同内容学习人数的聚合信号。不得连接身份或留存可识别的位置关联，优先端上计算或位置粗化，具体技术方案待定；定位为陪伴。
- **物理沉淀与导出**：可将一枝、一条连接、一页或趣味知识作为策展切片导出，用户选择或系统建议，系统不代为打印；使用 PDF 等开放标准，允许任意打印店承接，模板质量高，但不为打印便利重塑内容。
- **专用终端**：平板形态，服务无感被动学习环境与用户主权。
- **表现与吸引**：允许趣味知识、向朋友展示、形式个性化及结构变化，目标仍为用户成长，不能转为平台参与度优化。
