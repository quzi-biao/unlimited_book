# 知识树与产品企划书实施记录（2026-11-20）

本轮仅修改本地源码、构建本地安装包，并在独立的本机 PostgreSQL 数据库中验证。没有提交、推送、部署，也没有修改用户提供的远程服务器。

## 本轮需求对照

| 需求 | 当前实现 | 验证或边界 |
| --- | --- | --- |
| 书架改为直观知识树 | 书作为根，父子分枝、已探索发光、未探索暗色；相邻可能性逐步展开；支持缩放、滚动和键盘选择 | 桌面、手机横竖屏、平板浏览器验证；保留已探索深层节点的祖先路径 |
| 无限模式从公共内容开始 | 新身份自动选择第一棵已发布公共树，已有节点直接打开；未准备的方向进入生成队列 | 首次进入没有 AI 调用；示例数据共两棵树、12 个节点 |
| 安全模式 | 服务端限制为选定的已发布公共树；不能创建新 AI 分枝；旧生成和书架接口也执行限制 | 集成测试直接请求接口，不能只靠隐藏按钮绕过 |
| 多年级公共树 | 编辑可创建多棵树，填写年级、外部范围、版本说明，添加父子节点，审核后发布；用户选择树 | 草稿不可见，空树、循环、跨树父引用和未审图文不可发布 |
| 按完整路径复用生成结果 | 不可变资源表按父标识递归携带血缘，区分文字／框选、裁图内容、问题、语言、画风、难度、模态、阅读目的、模型和提示词版本 | 同一路径并发只生成一次，缓存命中不占用生成额度 |
| 用户扩展回流云端 | 新内容通过图文模型复核后存云端，进入待人工审核队列；编辑决定是否批准、挂到哪棵草稿树并发布 | 模型复核与公共树发布是两道不同关口；被拒资源停止云端访问 |
| 本地和云端均保存 | IndexedDB 保存快照、跨树归档、待同步事件、生成任务、图片和已获取音轨；PostgreSQL 保存资源、个人状态、完整事件与权限 | 断网笔记、离线重启、恢复联网、超过 200 条分批补传、跨设备账号验证 |
| 数据一致性 | 事件 UUID 去重、读者级事务锁、服务端确认后清理 outbox、先持久化快照再删待发事件；笔记保留全部历史；自评按发生时间重放 | 乱序、重传、并发、整批回滚和账号切换测试 |

## 数据与同步约定

1. 公共内容和个人探索分离。公共图文通过不可变资源标识共享；每个读者独立保存点亮、父引用、笔记、自评和连接。缓存不包含另一个读者的身份、笔记或学习状态。
2. 文字／框选的父资源 key 递归固定整条生成血缘；模型、端点、引擎和提示词变更会改变标识。框选坐标归一化，由后端从有权访问的父图裁切，裁图字节参与标识。
3. 同一生成标识由数据库事务锁及租约协调。占额和租约同事务提交；失败返还；进程中断后过期租约可以重领。图、解释、音轨与生成标识的关系保存在资源／音轨任务表。
4. 笔记显示值按发生时间与事件 ID 确定，全量历史保留。回想事件按时间与 ID 排序重放，避免设备 A、B 的不同补传顺序改变最终状态。设备时钟仍需正常；超前五分钟以上的事件拒绝。
5. 本地快照落盘完成后才清除已确认 outbox；中间崩溃时允许重复发送，服务端去重。本地渲染不重复投影快照中已包含的事件。
6. 设置带修订号，跨设备冲突返回 409 并刷新；模式、监护权限和套餐由服务端决定。切换账号后旧 outbox 继续按原账号保存，不能补传到新账号。
7. 浏览器 IndexedDB 升级到版本 2，新增跨树归档。安全模式只展示安全树，导出仍可由本人带走之前下载的个人历史。撤回内容的本机副本不能在离线设备上即时回收。
8. iOS 用固定 loopback origin 和固定命名的 WKWebsiteDataStore 持久化；仅监听 `127.0.0.1`，静态目录限制为安装包资源。排查用的凭证／存储探针已移除。

## 本地查看与复现

- 读者生产预览：`http://127.0.0.1:5186/`。
- 本轮 API：`http://127.0.0.1:8898/`。
- 本轮 PostgreSQL：Docker 容器 `unlimited-knowledge-test-db`，仅本机端口 `55438`，数据库 `knowledge`。
- 迁移演练数据库：同一独立容器的 `knowledge_migration`。
- 用户已有的 `8888`／`5175` 服务未用于此次测试，也未替换。

开发机需要 Node、pnpm、PostgreSQL；数据库 URL 必须显式指向本机测试库。以下命令分别在相应目录运行：

```sh
# server，DATABASE_URL 事先设为本机隔离库
pnpm exec prisma generate
pnpm exec prisma db push
pnpm exec node scripts/seed-knowledge.js
KNOWLEDGE_INTEGRATION=true pnpm test
pnpm dev:knowledge

# web
pnpm build
VITE_API_TARGET=http://127.0.0.1:8898 pnpm exec vite preview --host 127.0.0.1 --port 5186
pnpm exec node --test tests/*.test.js
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs pnpm exec node tests/knowledge-browser.mjs

# admin-frontend
pnpm build

# android，在本机 JDK 和 Android SDK 配置就绪后
./gradlew :app:assemblePhoneDebug :app:assembleTabletDebug --no-daemon
```

`db push` 仅用于空的隔离开发数据库；已有数据库的结构变更保留为可审查的 SQL，本轮没有在任何远端运行。示例 seed 也只允许本机数据库，不覆盖已有编辑数据。

首次进入可直接探索公共树。要检查无限生成流程，可用本地成人测试账号或经监护人许可的儿童账号，由管理端配置当月额度。真实生成需配置模型密钥、运行对应提示词的黄金集评测并通过后激活；未配置时会明确返回未就绪，而不会展示假生成结果。
