2026-11-23 用户先暂缓“整个软件是一本书，还是每个话题一本书、软件是书架”的概念决定，随后向客户确认并反馈：“一个用户一个知识树”。据此，个人知识结构统一为每个用户一棵持续生长的树，各话题及其探索路径属于其中的节点与分枝；当前每个根话题的界面分组不代表多棵隔离的个人知识树。用户将此方向对应为此前讨论的“视角 A”。本地实现将书架入口、树图和阅读页统一展示为个人「无限之书」，不同真实根话题从个人视觉根部分出，保留独立搜索作为独立话题的关系，不为了画面相连而虚构父子节点。展示用个人根不写入知识数据、不参与生成或学习轨迹。

这一方向下，多个云端公共知识树作为可选择的内容来源，不能据此将用户的全部探索历史理解成多本独立个人书。无限／安全模式仍遵循已有权限规则。统一树的呈现不改变真实探索关系：独立搜索的话题不能仅为连成一棵树就被挂到当前阅读话题之下，需与明确沿父页的深入探索区分。不同真实根话题的阅读翻页范围仍各自保持，避免左右翻页跨到无关主题。

## 核心定位

- 产品是 AI 驱动、持续生长的个人知识库与思想容器；“终身学习工具”是原文的阶段性工作定义。
- 单一版本、全龄贯穿，从认字到成年；不另设儿童版和成人版，差异在能力、阅读目的、监护人许可及逐步移交。
- 软件是内核，专用平板是外壳；规划中的个人库跟随账号，手机、平板、桌面、网页进入同一座库。
- 内容随用户问题和阅读路径按需生成，持续形成个人知识树；产品目标不局限于 AI 生图、固定图册或内容库存。
- 产品独立于“原创土壤”“青少年教育”“博物村”，不是它们的下属或延伸项目。
- 首批用户由父母购买硬件、孩子使用；商业模式为硬件售卖加按月 token 调用额度。token 是算力对价，不交换数据或注意力主权。原文未规定具体售价、点数换算或分润。

## 交互与学习模型

分形阅读：每个知识节点包含“内容、主模态、锚点集、出口集”；依据锚点展开时生成结构同型的新节点，可继续递归。主模态由解码能力与阅读目的决定：低龄以图像为主，目的性成人阅读偏重文本，感受性阅读可偏图像与视频。

被建模的学习轨迹是所有功能的共同基础，包含知识节点、连接边和掌握状态（擦过／练过／连过／真正长在自己身上），记录打开、停留、回看等行为。轨迹不是单纯页面列表。

四层功能：

1. 积累与轨迹：知识树亮部代表走过的路径，暗部展示有限的相邻可能性，不预设全图、不强推探索。科学呈现因果推导；人文呈现多条相邻进展并标为临时，不呈现为唯一关系。
2. 被动无感掌握：间隔重复与最近发展区难度调节，判断记忆及认知状态，不判断思想价值。
3. 主动连接：按远域优先、意外度、当下相关生成连接候选，用提议而非定论呈现，判断归用户。
4. 被改变的人：培养独立连接与审查能力；纠错必须可见且由用户参与，不能混入无感学习。

知识树同时承担导航、认知外化、成就呈现。完成感来自读完一页、一次探索成书、一个领域逐渐茂密；在探索后显现，不以前置奖励、强制任务或进度条驱动。此处的学习进度限制不等同于禁止技术加载状态。

## 用户主权与反茧房

- 数据归用户，可导出、可携带、可脱离；系统提供提示，不替用户判断和决定。
- “吸收被动、判断主动、探索主动”；无感机制仅服务掌握节奏，不用于真相判断或纠错。
- 表现与推荐的目标是用户长进，不是平台参与度或停留时长；需要架构层面的约束。
- 形式可以个性化；内容筛选受反茧房规则约束，不能只投喂既有偏好。
- 原文后段给出分级治理：目的性模式路径服务目标；成人感受性模式不设配额，仅提供自我观察；未成年人所有模式强制反茧房。
- 未成年人推荐出口约三分之一面向偏好之外；若探索领域分布持续收窄，放大新颖性配额。“约三分之一”是规划口径，尚无实现和验收参数。
- 模型可替换；长期资产是轨迹、提示词装配、反茧房逻辑、用户偏好理解、评测集与装配日志。

## 儿童与监护人

儿童期建立在监护人许可之上，越界需授权，未成年人的有限之书模式由监护人决定。

监护人观察端三条禁令：不人格测评、不展示覆盖率、不主动给补全提示；不与平均水平比较。覆盖率地图只属于编辑后台。

可呈现四类内容：独特知识树回顾、纯行为事实、用于亲子沟通的问题、透明可重置且可逐项关闭的偏好理解。每周探险报包含新枝、表达时刻与沟通建议，优先用小程序或网页，不另做监护人独立 App。成人对应自我观察与知识树月报，只呈现不干预。

有限之书是同一轨迹的可选诊断视图：用户或监护人主动采纳外部范围后看缺口，措辞为“可选补”，不是“你不足”。不能另建第二本隔离的书；外部课程图谱规划先从人教版开始。

## 其他模块

- 邻域共学：默认关闭，只显示约 1／3／5 公里内同内容学习者的聚合数量，不识别个人；儿童开启需监护人授权。位置方案优先端上计算，或明确粗化与三元组不存储，不留存、不连身份。这里指邻域聚合数据，不是禁止个人库按账号保存。
- 物理导出：用户选择或接受建议后，将一枝、一连接、一页等策展切片输出为开放打印格式（如 PDF）。系统不代用户打印，不能为了好打印而重塑内容。
- 专用终端：平板载体服务于无感学习环境与用户主权。

## 生成引擎 L0 至 L3 加 S

| 层级 | 规划职责 |
| --- | --- |
| L0 全局基座 | 真实对象、核心知识、讲解、多个出口；适龄语言、事实准确与基础画风。集中维护，变更须版本管理、评测回归和灰度。 |
| L1 懂读者 | 理解水平、长期兴趣、偏好讲法与画风；风格和音色选择是显式信号，不给用户贴定性标签。 |
| L2 路径上下文 | 携带父页已讲内容、追问链、视觉基因，承接内容、避免重复并保持同一本书的连续性。 |
| L3 当前请求 | 本次话题、区域语义、期望页面类型及即时约束。 |
| S 安全底线 | 适龄、敏感话题、事实性、禁止诱导、生成标识；不可被其他层稀释。 |

S 的三道关：请求过滤 → 置顶硬约束 → 生成后文本与图片双审。冲突规则：S 否决一切；表现参数 L3 > L2 > L1 > L0；结构与准确性要求只升不降；冲突写入装配日志。

多模型流水线：区域理解优先快响应；话题理解及配图可异步入探索队列。黄金话题集覆盖事实、适龄、安全、风格一致性，模型或提示词变化要回归。首页及家长可见内容优先强模型，扩展任务按成本质量路由。

原文提出的模型选择标准还包括中文儿童语言评测、图像一致性、单页成本，以及国内部署使用完成相应备案的模型。这是企划书中的要求，本次未核实任何供应商的合规或备案状态。

建设顺序：先 S 三道关与 L0，再 L2；评测集与装配日志同步；L1 个性化最后。
