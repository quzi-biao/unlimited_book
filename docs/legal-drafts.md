# 无限之书协议与隐私草案

## 1. 用户服务协议草案

本产品面向家庭用户提供知识阅读、内容探索和相关服务。用户在使用前应确认已阅读并理解本协议。

用户同意：

- 仅将产品用于家庭学习和知识探索用途。
- 不进行违法、违规或损害他人权益的使用。
- 理解内容可能由系统生成，实际使用中应结合家庭教育判断。
- 如对购买、退款、售后或服务有疑问，应通过官方渠道联系。

平台权利：

- 有权根据运营需要更新内容、服务规则和使用方式。
- 有权对违规使用、异常行为或风险内容进行限制。

## 2. 隐私政策草案

我们会收集必要信息用于提供服务、账户管理、售后支持、设备识别和体验优化。

可能涉及的信息包括：

- 设备信息
- 使用记录
- 订单与支付记录
- 售后与客服记录

我们承诺：

- 仅为提供服务所必需的目的使用信息。
- 不会随意向无关第三方披露个人信息。
- 用户可通过官方渠道申请查询、更正或删除相关信息。

## 3. 儿童个人信息保护规则草案

本产品主要面向未成年人家庭场景，平台将尽合理注意义务保护儿童信息安全。

规则要点：

- 仅收集服务必要信息。
- 对儿童信息采取更严格的访问和使用控制。
- 不会将儿童信息用于与产品无关的营销用途。
- 若监护人要求，可依法依规处理相关信息。

监护人义务：

- 监护人应确认孩子在可监督环境下使用产品。
- 监护人应理解内容服务的辅助性质，并结合家庭教育进行判断。
